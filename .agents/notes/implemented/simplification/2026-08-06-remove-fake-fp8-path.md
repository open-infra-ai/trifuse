# Agent Note: 整条删除伪 FP8 路径（实为 uint8 均匀线性量化）

Status: implemented

## Problem

仓内曾有一条标注为「FP8 E4M3」的量化/kernel 路径。审查发现它实际是存储在
`uint8` 中的**均匀线性量化**，并不编码 E4M3 的指数与尾数。把它留着，
等于把 INT8 路径误当 FP8 教材——错误标注比没有实现更有害。

## Decision

v2.0.0 中**整条删除**该路径：量化 GEMM kernel、测试、示例与相关文档全部
移除，不保留改名后的「修正版」。本仓只保留三条可被独立参考实现验证的
Transformer 推理路径。

## Alternatives considered

- **改名保留为 uint8 量化** — 代码不算浪费最强；但本仓定位是「可验证的
  融合算子对照」，一条普通的 INT8 线性量化不承载教学差异点，还会暗示
  仓内支持低精度训练方向。
- **实现真正的 FP8 E4M3** — 方向正确；但当时硬件/栈不具备验证条件，
  没有差分参照的实现等于再制造一条「伪 FP8」。

## Consequences

- **收益**：仓内每条路径都有参考实现与差分测试背书，无误导性能力声明。
- **代价**：少了一个量化相关条目；真正的 FP8 支持留给具备验证条件时
  另立笔记。

## Verification

CHANGELOG `2.0.0`（2026-08-06）记录删除范围；README 对删除原因有说明；
`rg -i fp8` 无命中残留。
